전화 대표 확인 필요
운영 시간 평일 10:00~18:00
이메일은 언제든 받고, 운영 시간에 차례로 답해요(보통 1영업일 안). 결제 · 환불 문의는 3영업일 안에 처리해요.

문의할 때 알려 주세요

  • 결제 · 운세 풀이: 주문번호 (설정 → 내 구매) · 결제 시각 · 상품 이름
  • 골드 · 소장: 로그인한 구글 이메일
  • 오류: 폰 기종 · 브라우저 · 화면 캡처

생년월일 · 카드번호 · 비밀번호는 보내지 마세요. 확인에 필요하지 않아요.

자주 묻는 질문

결제했는데 풀이가 안 열려요

설정 → 내 구매 → '주문번호로 다시 받기'에 주문번호와 복원 코드를 넣어 보세요. 그래도 안 되면 주문번호와 함께 연락 주시면 다시 열어 드리거나 전액 환불해 드려요.

운세 풀이를 환불받을 수 있나요?

결제 즉시 열리는 콘텐츠라 단순 변심 환불은 어려워요. 오류로 못 받았거나 중복 결제했다면 전액 환불해요. 환불 · 청약철회 정책

충전한 골드를 환불하고 싶어요

결제 후 7일 안이면 쓰지 않은 골드만큼 환불해요. 7일이 지나면 남은 충전 골드에서 수수료 10%를 빼고 환불해요. 보너스 골드는 환불 대상이 아니에요.

아이가 허락 없이 결제했어요

미성년자가 법정대리인 동의 없이 한 결제는 취소할 수 있어요. 주문번호와 함께 연락 주시면 필요한 확인 서류를 안내해 드려요.

폰을 바꾸면 골드 · 소장 게임은요?

구글로 로그인하면 골드 · 소장 · 소장 게임 저장이 계정에 남아 새 폰에서도 그대로예요. 로그인 없이 산 운세 풀이는 주문번호 + 복원 코드로 다시 받을 수 있어요.

골드 유효기간이 있나요?

충전 골드 5년, 보너스 골드는 받은 날부터 1년이에요. 쓸 때는 보너스 골드부터 써요. 유료 서비스 안내

제 생년월일은 어디에 저장되나요?

이 폰(브라우저)에만 저장돼요. 유료 풀이를 만들 때 한 번 서버로 보내고 바로 버려요. 운세 화면 '내 정보 지우기'로 언제든 지울 수 있어요.

점쟁이 · 너랑의 답은 누가 쓰나요?

생성형 AI가 만들어요. 재미 · 참고용이고 실제 상담이 아니에요. 이상한 답은 캡처해서 알려 주세요. AI 생성 콘텐츠 안내

탈퇴하고 정보를 지우고 싶어요

설정 → '탈퇴하고 내 정보 지우기'로 바로 지울 수 있어요. 남은 충전 골드가 있다면 탈퇴 전에 환불을 먼저 요청해 주세요.

이용 기록을 보내고 싶지 않아요

설정 → '이용 기록 보내지 않기'를 누르면 통계 수집이 꺼져요. 서비스 이용은 그대로 할 수 있어요.
