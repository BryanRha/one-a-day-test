## 원어데이 BM (v2.8.0 · docs/bm-policy.md 를 따름)
- 파일: `src/oad_bm.js`(공통 · 수정 금지) · `src/bmflow.js`(hello · 소리 멈춤 · 광고 횟수 · 판 끝 전면 · 기록 · 장식 · 문구) · `src/core/cont.js`(이어하기 권유 규칙) · `src/core/help.js`(응원 선물 규칙)
- 가격은 서버 SHOP.ocean 만: continue 🪙20 · continue2 🪙40 · boosters 🪙60 · deco 🪙100(item)
- 이어하기: 이동을 다 썼을 때 목표 60% 이상 · 4레벨부터 · 처음 3판 이후만 → 칭찬 + 10초 고리 → 첫 번째 [광고 +5]·[🪙20 +5] 같은 크기(소장자 [무료로 +5]) · 두 번째 [🪙40]만 · 판당 2번 · 시간 끝나면 조용히 결과(칭찬 먼저). 게임 코인/보유 +5 부스터 길은 그대로. 이어해서 깨면 '역전 성공!'
- 광고 보상: 시작 창 [광고 → 삼지창 1](하루 3) 옆에 [🪙60 부스터 3종] · 실패 후 +5수(판당 1 · 하루 3) — 게임 쪽 횟수는 save.bmAds
- 판 끝 전면: 결과 창에서 다른 화면으로 넘어갈 때 `bm.interstitial('round_end')` (실패 순간 X)
- 응원 선물(단계형): 같은 레벨 3연속 실패 → 다음 시작 때 '이동 +1' · 6번째부터 '+2' · 하루 2번 · 이동 절반 넘게 쓰고 그만둔 판도 실패로 셈 · 레벨 깨거나 바꾸면 0 · help_eligible(on 1/0) → help_offer → help_take/decline. 크기 근거 `node tools/help_bot.js 60 5`: 이어하기 1회 +14.7p, +1수 0.22배, +2수 0.45배 (+3수 0.62배라 안 씀)
- 꾸미기(바다 복원 화면 '꾸미기'): 소장자 전용 '달빛 고래'(무료) · 🪙100 '진주 등불'(hello().items 로 복원) · 켜고 끄기
- 원어데이 밖(hello().ok=false): 골드 · 광고 · 꾸미기 버튼 없음, 예전 그대로
- 몰래 난이도 낮추는 장치: 없음 (연승 보너스는 모두에게 같은 공개 규칙)
- 시험: `node tools/bm_test.js`(규칙 2만 판) · `node tools/f2p_check.js`(무과금 500레벨) · `node tools/browser/bm_e2e.mjs`(?oadtest=1 흐름, 캡처 docs/shots_bm/) — 개발 서버는 동시 요청이 많아 기본 http.server 대신 큐가 큰 서버를 쓸 것(기본은 ERR_SOCKET_NOT_CONNECTED)

## 폴더
- `../assets/tools/*.py` — 그림·효과·사운드 생성기 (`python3 assets/tools/build.py`, 사운드는 `gen_audio.py`)
- `src/` — 게임 (Phaser 3.90, 빌드 도구 없음). 규칙 엔진 `src/core/engine.js`
- `tools/` — 튜닝(`tune.js`, `tune_merge.js`), 레벨 생성(`genlevels.js`, `gen500.js`), 동기화(`sync.js`), 배포(`deploy_pages.sh`), 테스트(`test_core.js`, `browser/e2e.mjs`)
- 자세한 규칙: `README.md`, 밸런싱 근거: `BALANCING.md`

## 다시 시작할 때
```bash
cd game
node tools/test_core.js                      # 엔진 테스트 (전 레벨 무작위 3000판)
node tools/sync.js --mirror                  # 리소스 반영 + ~/dessert-pop-dist 로 복사 (OneDrive 폴더는 개발 서버가 못 읽음)
bash tools/deploy_pages.sh "변경 내용"        # GitHub Pages 배포 (src/config.js 의 VERSION 먼저 올리기)
```
- 화면 테스트: puppeteer-core 를 아무 폴더에 설치(`npm i puppeteer-core`)하고 `tools/browser/e2e.mjs` 와 `autoplay.js` 를 복사해서
  `node e2e.mjs http://localhost:3201 1 500 ./shots` (게임은 `~/dessert-pop-dist` 에서 `python3 -m http.server 3201`). 서버 하나에 브라우저를 여럿 붙이면 로딩 오류가 나므로 포트를 나눌 것.
- 사운드 재생성에는 numpy 필요 (`pip3 install --user numpy`).

4. **앱 출시** — 이름은 "웨일 테일"로 바뀜(화면 · 로고). 저장소 · 주소 이름은 아직 dessert-pop
5. 원어데이 BM 실측 후 조정(권유 60% 기준 · 선물 크기) · 주간 이벤트

## 정해 둔 원칙
- 원작(캔디크러시) 에셋·코드·레벨 데이터는 쓰지 않음 — 관찰한 장르 원칙만 참고
- 니모·도리 디자인과 이름 사용 금지
- 사행성 요소 금지 (현금·경품 교환, 무작위 뽑기). 보상은 내용을 미리 보여 줌
- 하트(생명) 대기, 랭킹은 넣지 않음 (로그인 없는 웹게임 특성)
